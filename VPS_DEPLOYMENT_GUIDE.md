## 4. Backend Setup (Port 5009 & PM2)

```bash
cd /var/www/company-connect/server
nano .env
```
Ensure your `server/.env` contains:
```env
MONGO_URI=mongodb+srv://shaesan177_db_user:gem-connect@cluster0.hezhrsb.mongodb.net/?appName=Cluster0
JWT_SECRET=b19a842f615e4f4b9319e7235b2e316a8d76c9035a7114b3d87a419c8f2b7d41
PORT=5009
CLIENT_URL=https://portal.gemshine.tech,http://localhost:5173
```
*(Save and exit nano: `Ctrl + O` -> `Enter` -> `Ctrl + X`)*

### 4.2 Backend dependencies & PM2 Start:
```bash
# Install backend packages
npm install --production

cd /var/www/company-connect

# Create logs directory
mkdir -p server/logs

# Start backend via PM2 using ecosystem.config.cjs (Runs on port 5009)
pm2 start ecosystem.config.cjs --env production

# Save PM2 process list (Auto starts on VPS reboot)
pm2 save
pm2 startup
# (Run the sudo env command generated by pm2 startup if prompted)
```

Test if backend is running on 5009:
```bash
curl http://127.0.0.1:5009/health
# Output: {"status":"ok"}
```

## 6. Nginx Configuration

Copy the Nginx configuration file to Nginx's `sites-available`:

```bash
# Copy config
sudo cp /var/www/company-connect/nginx/portal.gemshine.tech.conf /etc/nginx/sites-available/portal.gemshine.tech.conf

# Enable the site using symlink
sudo ln -sf /etc/nginx/sites-available/portal.gemshine.tech.conf /etc/nginx/sites-enabled/

# Test Nginx syntax
sudo nginx -t
```
Output should be: `syntax is ok` & `test is successful`.

Restart Nginx:
```bash
sudo systemctl reload nginx
```

## 7. SSL Certificate Setup (HTTPS)
Free Let's Encrypt SSL certificate activate panna Certbot command run pannunga:

```bash
sudo certbot --nginx -d portal.gemshine.tech
```
- Enter your email address when prompted.
- Agree to terms (`Y`).
- Choose automatic HTTP -> HTTPS redirect (`2` or default).

Certbot will automatically update the Nginx configuration with SSL keys!

## 9. Troubleshooting & Useful Commands

### PM2 Commands (Backend):
```bash
# View backend status
pm2 status

# View live backend logs
pm2 logs company-connect-server

# Restart backend
pm2 restart company-connect-server

# Stop backend
pm2 stop company-connect-server
```

### Nginx Commands:
```bash
# Test configuration
sudo nginx -t

# Reload Nginx without downtime
sudo systemctl reload nginx

# View Nginx access & error logs
sudo tail -f /var/log/nginx/error.log
sudo tail -f /var/log/nginx/access.log
```

### Port 5009 Check:
```bash
# Check if port 5009 is listening
sudo netstat -tlpn | grep 5009
# or
sudo lsof -i :5009
```
